# NSW Cyber Security Guidelines – Local Government: Foundational Requirements
Summary of section 7 of the guidelines (issued January 2025). Detailed
requirements (section 8) expand each item; see the source PDF.

## 1. Govern and identify
1.1 Allocate and perform roles and responsibilities for cyber security.
1.2 Executive-level governance committee with authority over cyber security, including OT/IoT.
1.3 ARIC briefed regularly on cyber risks, issues and corrective actions.
1.4 Develop and maintain a cyber security strategy.
1.5 Formalised plans, policies and processes for cyber security practices.
1.6 Asset inventory management and asset dependencies.
1.7 Assess and identify Crown Jewels and classify systems.
1.8 Govern identification, retention and secure disposal of data.
1.9 Define risk tolerance and appetite; manage cyber risks.
1.10 Identify and manage third-party service provider risks (1.10.1 inventory; 1.10.2 contractual incident/breach notification; 1.10.3 monitor adherence; 1.10.4 contract security and break clauses).
1.11 Vulnerability management (1.11.2 includes actioning Cyber Security NSW alerts).
1.12 Cyber security assessed in change management (1.12.3 test controls after significant change).

## 2. Detect, respond and recover
2.1 Event logging and continuous monitoring for anomalous activity.
2.2 Cyber incident response plan, exercised annually, post-incident reviews, incident register.
2.3 Report cyber incidents and threat information to Cyber Security NSW.
2.4 Cyber in business continuity and disaster recovery planning.

## 3. Protect
3.1 Awareness activities and mandatory training.
3.2 Access controls (authorised access only; timely removal; access reviews).
3.3 Patch applications (E8). 3.4 Patch operating systems (E8). 3.5 MFA (E8).
3.6 Restrict administrative privileges (E8). 3.7 Application control (E8).
3.8 Microsoft Office macro settings (E8). 3.9 User application hardening (E8).
3.10 Backups (E8).
3.11 Secure configurations. 3.12 Data security controls (3.12.1 scan manually imported data; 3.12.2 encryption).
3.13 Email security (DMARC, SPF, DKIM). 3.14 Endpoint protection. 3.15 Network security (segmentation).

Items 3.7–3.9, 3.13, 3.14 and most of 1.x/2.x are organisational: mark them
"out of scope for code audit" unless the project file says otherwise.
